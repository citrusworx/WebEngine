# KiwiPress — Headless WordPress Integration

KiwiPress is a WebEngine package, not one of the eight libraries in the supplied inventory. Its product purpose is a headless WordPress pathway that can serve as a bridge toward WebEngine.

- Inspect `packages/kiwipress`, `docs/kiwipress/`, and actual exports before coding.
- Respect WordPress API, auth, gateway, native CMS, and transfer boundaries as implemented.
- Keep WordPress-specific concerns inside KiwiPress rather than contaminating independent libraries.
- Prioritize auth, permissions, data integrity, migrations, compatibility, and reversible transfer operations.
- Never assume a transfer feature is production-ready solely because it appears in docs or roadmap.
