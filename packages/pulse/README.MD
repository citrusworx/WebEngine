# Pulse

KiwiEngine's Pulse is a package dedicated to creating inter-application Event & Triggering. Need to log a customer into a certain funnel after signing up at a particular landing page?

## Pulse Function Examples

- Send email to admin when user has 3 unsuccessful login attempts
- Senf email to sales when user has requested quote
- Send email to IT when a user has submitted a ticket
- Send Data from app 1 to app 2

This library takes inspiration from Zapier but with more focused and deeper functionality.
