# @citrusworx/grapevine

Provider integrations used by CitrusWorx infrastructure workflows.

## Install

```bash
npm install @citrusworx/grapevine
```

## Usage

```ts
import * as Grapevine from "@citrusworx/grapevine";
```

The current public entrypoint re-exports the DigitalOcean provider integration.

## Development

```bash
yarn workspace @citrusworx/grapevine build
yarn workspace @citrusworx/grapevine test
```
