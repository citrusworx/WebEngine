# @citrusworx/types

Shared CitrusWorx type definitions for deployments, environments, projects, domains, and blueprints.

## Install

```bash
npm install @citrusworx/types
```

## Usage

```ts
import type { Blueprint, Environment, DeploymentManifest } from "@citrusworx/types";
```

The package also exposes typed subpaths for selected modules, including deployment and environment definitions.

## Development

```bash
yarn workspace @citrusworx/types build
```
