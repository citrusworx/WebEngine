# @citrusworx/sigjs

Signal and JSX runtime utilities for CitrusWorx front-end packages.

## Install

```bash
npm install @citrusworx/sigjs
```

## Usage

```ts
import * as Sig from "@citrusworx/sigjs";
```

Additional subpath exports:

- `@citrusworx/sigjs/jsx-runtime`
- `@citrusworx/sigjs/jsx-dev-runtime`
- `@citrusworx/sigjs/sig-router`

## Development

```bash
yarn workspace @citrusworx/sigjs build
yarn workspace @citrusworx/sigjs test
```
