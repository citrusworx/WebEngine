# Examples

Standalone apps that depend only on `@citrusworx/sigjs`. The [counter](./counter) example pins `@citrusworx/sigjs@^1.0.0` from npm so a fresh consumer does not need this monorepo. The lock records **1.0.0** (published 2026-10-29). The workspace `package.json` is **1.0.0**.

| Example | What it shows |
|---------|----------------|
| [counter](./counter) | Vite + JSX, `Signal`, reactive props/children, `SigRouter` (`/`, `/about`, `/user/:id`, `*`) |
