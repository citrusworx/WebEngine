# Examples

Standalone apps that depend only on `@citrusworx/sigjs`. The [counter](./counter) example installs `@citrusworx/sigjs@^0.3.0` from npm so a fresh consumer does not need this monorepo.

| Example | What it shows |
|---------|----------------|
| [counter](./counter) | Vite + JSX, `Signal`, reactive props/children, `SigRouter` (`/`, `/about`, `/user/:id`, `*`) |
