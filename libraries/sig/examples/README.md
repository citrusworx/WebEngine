# Examples

Standalone apps that depend only on `@citrusworx/sigjs`. The [counter](./counter) example pins `@citrusworx/sigjs@^0.7.0` from npm so a fresh consumer does not need this monorepo. That version is not published yet.

| Example | What it shows |
|---------|----------------|
| [counter](./counter) | Vite + JSX, `Signal`, reactive props/children, `SigRouter` (`/`, `/about`, `/user/:id`, `*`) |
