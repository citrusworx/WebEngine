# @citrusworx/dns

DNS and registrar utilities for the CitrusWorx ecosystem.

## Install

```bash
npm install @citrusworx/dns
```

## Usage

```ts
import { DNS, ResellerClub } from "@citrusworx/dns";
```

The package exports:

- `DNS`
- `ResellerClub`
- provider and availability types used by CitrusWorx domain workflows

## Development

```bash
yarn workspace @citrusworx/dns build
yarn workspace @citrusworx/dns test
```
