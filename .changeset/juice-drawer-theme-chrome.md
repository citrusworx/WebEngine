Add themeable drawer chrome roles (`--juice-drawer-*`). Core CSS consumes overlay wash, panel fill/border/shadow, and close fill/color/hover/focus with light fallbacks. Aquaflux, KiwiPress, Citrusmint, Tide, and generated themes bind those roles from existing tokens. Tide stays a dark scrim and dark panel. Edge is `[drawer]` / `[drawer="left"|"right"]`; optional width is `[drawer-size="sm|lg"]`. Drawer runtime is not in this cut.
