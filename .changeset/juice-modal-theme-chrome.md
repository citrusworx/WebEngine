Add themeable modal chrome roles (`--juice-modal-*`). Core CSS consumes overlay wash, panel fill/border/shadow, and close fill/color/hover/focus with light fallbacks. Aquaflux, KiwiPress, Citrusmint, Tide, and generated themes bind those roles from existing tokens. Tide stays a dark scrim and dark panel. Dialog runtime is not in this cut.
