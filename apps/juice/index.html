Juice is strongest as a shared structural language — not a utility-class clone, and not a heavyweight React runtime.

CSS-first

Import the core stylesheet, add a theme, set theme="…" on the root. Layout and surfaces work before any JavaScript runs.

Attribute-driven

stack, row, grid, gap, hero, card, and cta stay in the markup. Wrappers own placement. Components own structure.

Composition

Juice owns shared structure, spacing, responsive behavior, and primitive surface hooks. App CSS stays small and intentional.

Juice owns structure. Themes own identity.

The same landing markup can wear KiwiPress, Tide, Citrusmint, or Aquaflux. Core CSS has no theme rules. Activate a theme with one attribute.

Structure

Layout primitives, spacing, page hooks, and component vocabulary stay in Juice. This page is mostly attributes.

Identity

Typography voice, color relationships, and semantic defaults live in the theme. KiwiPress is the richest product reference; Tide is the dark product / SaaS face. 

import "@citrusworx/juiceui/styles";
import "@citrusworx/juiceui/styles/themes/kiwipress";
import "@citrusworx/juiceui";

Honest Beta

Juice Beta is a CSS-first, attribute-driven styling and composition system with strong layout, token, typography, icon, and page-structure support, a documented theme contract, and a supported subset of motion attributes.

Ready today

Attribute-driven styling, layout primitives, spacing, color tokens, typography, and icons are the strongest layers. Use those with confidence.

Still settling

Cards, buttons, forms, nav, and the JS entry are Emerging. Config-driven branding is Draft. Juice is not a mature component framework and does not pretend to be one.

Start with structure, then pick a face.

The getting-started page is next. Until it ships, the monorepo docs in docs/juice are the source of truth.
