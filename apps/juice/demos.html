Banner

Inline alert / callout — not a toast stack and not a dialog. Layout is [banner] / [banner="full"]. Status is banner-tone="info|success|warning|error". Dismiss with [banner-close]. No Escape steal. Reload to bring a dismissed banner back.

Menu

APG menu button: [menu-root] wraps an opener plus [menu]. Use <div menu>, not the HTML <menu> element. Closed vs open is native hidden on the panel. Distinct from popover, combobox, and native <select>.

Recent

File uses [menu-button] chrome. Actions is a plain themed CTA opener with menu-root="top". Arrow keys and Escape follow the APG menu-button contract.

Switch

APG switch. Boolean [switch] on a <button type="button">. The host is the track. Click, Enter, and Space toggle. Binary aria-checked only — no tri-state. A checkbox host is the secondary story. Still Emerging.

The label beside the control is the accessible name. The runtime does not invent one. aria-checked="mixed" coerces to off.

Slider

APG slider. Horizontal [slider] owns a [slider-thumb]. [slider-fill] is optional. Arrows, Home, End, Page Up, and Page Down move the value. Pointer jumps and drags. Not a native <input type="range">. Still Emerging.

Missing bounds default to 0 and 100. Thumb values win over the host. The runtime writes role="slider" and --juice-slider-ratio. It does not rewrite aria-valuetext. Vertical and multi-thumb are out.

Checkbox

APG checkbox. Boolean [checkbox] on a button. The host is the box. Click, Enter, and Space toggle. Binary only — not [switch], and not a menu menuitemcheckbox. Still Emerging.

A wrapping label names the control. Native <input type="checkbox" checkbox> is the secondary host: paint follows :checked, and the runtime keeps aria-checked in step.

Radio

APG radio group. [radio] options live inside [radiogroup]. Selection is exclusive. Arrows move and wrap. Enter, Space, and click select. Orphans outside a group are ignored. Checkbox and radio are two runtimes. Still Emerging.

The group name is the author aria-label. Each option takes its name from the wrapping label. Exclusivity is the nearest [radiogroup], not a native name.

Breadcrumb

Light trail. [breadcrumb] with [breadcrumb-item] crumbs. An unlabeled <nav> is named Breadcrumb. One aria-current="page" stays — author current wins, otherwise the last crumb. Not site [nav], not a router, and not a wizard step tracker. Still Emerging.

Progress

APG progressbar. Authors write <div progress>, not <progress>. Determinate sync writes aria-valuenow and --juice-progress-ratio. progress="indeterminate" clears the current value and slides the fill. No keyboard and no pointer. Still Emerging.
