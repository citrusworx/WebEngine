Honest Beta · Emerging themes

Four shipped faces. Same structure.

Juice owns layout, spacing, and the composition vocabulary. Themes own identity — fonts, palette, surfaces, and semantic defaults. Safe to use: KiwiPress, Tide, Citrusmint, Aquaflux. Blush and anything under _draft stay unpublished.

Juice owns structure. Themes own identity.

A design system that ships one look is a theme pretending to be a system. Juice keeps the shared language; each face decides how that language should feel.

Structure

stack, row, grid, gap, and hooks like hero, card, panel, badge, and cta stay in Juice. Themes do not redefine layout primitives.

Identity

Type pair, page atmosphere, accent, surface recipes, and semantic defaults live in the theme. Swap theme="…" — the markup does not change.

Import core, import a theme, set theme="id"

Core CSS has no theme rules. This showcase imports all four shipped faces so the switcher can swap the root attribute. A product usually imports one. The full install path stays on Getting started — not duplicated here. 

import "@citrusworx/juiceui/styles";
import "@citrusworx/juiceui/styles/themes/kiwipress";
<body theme="kiwipress">…</body>

Depth stays in docs/juice

This page is a gallery, not a rewrite of the theme contract. Named surfaces, chrome roles, and generator shape live in the docs tree.

What a theme may add

Aquaflux exposes aqua-card, aqua-panel, and aqua-hero. Tide exposes tide-card and tide-panel. KiwiPress paints Juice primitives instead. Citrusmint ships none. Use those names only when the theme documents them.
