Attributes and styles

Juice keeps intent in markup. Attributes are the styling API — layout, type, color, spacing, sizing, shadows, icons, and component hooks. Styles explains the three layers: Juice attributes, theme CSS, and small app exceptions.

Honest Beta

Juice Beta is a CSS-first, attribute-driven styling and composition system. Layout, tokens, typography, and icons are the strongest layers. Runtimes and library themes are Emerging. This page is an index into on-site Juice Docs.

Ready today

Attribute-driven styling, layout primitives, spacing, color tokens, typography, and icons. Use those with confidence.

Still settling

Cards, buttons, forms, nav, and the JS entry are Emerging. Config-driven branding is Draft. Juice is not a mature component framework and does not pretend to be one.
